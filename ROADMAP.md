# Roadmap

## Phase 0 — Setup (this week)
- [ ] Decide which room to build first (recommend: whichever you have an account/budget ready for)
- [ ] Create accounts: Etsy shop + Printful/Printify (if starting POD), or YouTube channel (if starting Shorts)
- [ ] Pick your AI stack: an LLM for text/copy (Claude/GPT), an image model for POD art, a TTS + video tool for Shorts
- [ ] Set a weekly budget cap for API + platform fees so the experiment stays bounded

## Phase 1 — One manual pass, end to end
Goal: produce **one real output** by hand, following the room's pipeline step by
step, before automating anything. This tells you which steps are actually
tedious (worth automating first) vs. fine to do manually for a while.
- [ ] Etsy: research 1 niche → generate 3-5 designs → list them
- [ ] YouTube: pick 1 content pillar → script + generate + publish 3 Shorts

## Phase 2 — Automate the worst step first
Don't automate the whole pipeline at once. Automate the single most repetitive
step (usually: bulk design generation, or bulk script generation), keep the
rest manual, and confirm output quality holds up before automating the next
step.
- [ ] Identify the most repetitive manual step from Phase 1
- [ ] Script/automate just that step
- [ ] Re-run the pipeline, compare output quality and time saved

## Phase 3 — Full pipeline automation per room
- [ ] Etsy: research → design → listing copy → upload, chained with minimal manual review
- [ ] YouTube: topic pick → script → voiceover → video assembly → upload/schedule, chained with minimal manual review
- [ ] Add a lightweight review/approval gate before anything goes public (avoid unsupervised publishing early on)

## Phase 4 — Feed the Research Hub
- [ ] Once a room has real performance data (sales, views, engagement), start
      logging it centrally instead of per-room
- [ ] Use that data to steer the next batch of niches/topics instead of guessing
- [ ] Only now consider a scheduled/autonomous research worker — before this,
      it has no real signal to work from

## Phase 5 — Scale
- [ ] Add a second room once the first is running with low manual upkeep
- [ ] Consider more rooms (other POD marketplaces, TikTok/Instagram Reels reuse of Shorts content, etc.)
