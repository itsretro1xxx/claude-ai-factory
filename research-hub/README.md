# Research Hub

The coordination room. It doesn't produce revenue directly — it decides what
the revenue rooms should make next, and tracks what's actually working so
effort isn't wasted guessing.

Don't build this as a "pipeline" yet. Start it as a shared notes process; only
turn it into automated AI workers once the revenue rooms exist and are
producing real performance data (see Roadmap Phase 4).

## Worker roles (once automated)

1. **Trend scout** — pulls signal on what's selling/trending in a given niche
   (Etsy search/trend tools, Google Trends, TikTok/YouTube trending topics).
2. **Niche/topic scorer** — ranks candidate niches or content pillars by
   estimated demand vs. competition.
3. **Performance analyst** — pulls sales data (Etsy) and view/engagement data
   (YouTube Analytics) and summarizes what's outperforming.
4. **Briefing writer** — turns the above into a short brief each room's
   workers can act on directly (e.g. "next 5 designs should target X niche
   because Y").

## Manual version (start here)

- A single running doc (or spreadsheet) with columns: niche/topic idea,
  source of the idea, why it might work, status (untested/testing/working/dead).
- Weekly: add 2-3 new candidate ideas, mark results for anything tested.
- Feed the "working" rows into whichever room matches them.

## Tools to consider later

- Etsy: eRank, Marmalead, or Etsy's own search/trend data for niche research.
- YouTube: YouTube Analytics API, Google Trends, TubeBuddy/VidIQ for topic research.
- A shared database (Airtable/Notion/simple spreadsheet) as the "knowledge base"
  both rooms read from and write results back to.
